# AqJol

Intercity travel app for Kazakhstan. Train tickets and station taxis in one place.
F29SO Software Engineering Group Project, Team 14, Heriot-Watt University Aktobe.

## Tech stack

- React Native + TypeScript (Expo): passenger app, driver app, website
- NestJS: backend API
- PostgreSQL + Redis: database
- Docker, GitHub Actions, Jest
